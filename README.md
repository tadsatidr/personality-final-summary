# Personality (KU) – final exam prep

Static study site for the Kasetsart University Personality class, built from the five lecture decks:

1. Personality Preparation for Job Application and Interview
2. Ethics & Communication for Entrepreneurs
3. Entrepreneurial Attributes and Basic Presentation Skills
4. Social Etiquettes for Entrepreneur: Business Etiquettes
5. Dining Manners & Etiquettes

Each deck has a summary, likely exam questions with answer outlines and a quiz. The site also has a mixed quiz, a searchable glossary, a list of slide issues and a printable cheat sheet. No exam guideline was provided, so it is general final-exam prep. Anything marked "Not from slides" is general background.

Pure HTML/CSS/JS, no build step. Open `index.html`, or publish on GitHub Pages:
Settings → Pages → Deploy from a branch → `main` / root.

Files: `index.html`, `style.css`, `script.js`, `.nojekyll`.
